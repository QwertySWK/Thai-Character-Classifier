# Thai Character Classifier (การจำแนกประเภทภาพตัวอักษรไทย)

## 1. แนวคิด ปัญหาที่ต้องการแก้ และประโยชน์
* **แนวคิดและปัญหา:** การแปลงเอกสารภาษาไทยที่มีฟอนต์หลากหลายให้เป็นข้อความดิจิทัลยังคงเป็นความท้าทายในระบบ OCR โครงงานนี้จึงพัฒนาแบบจำลอง Machine Learning เพื่อจำแนกภาพตัวอักษรไทย สระ วรรณยุกต์ ตัวเลข และสัญลักษณ์ต่างๆ อย่างแม่นยำ
* **ประโยชน์:** สามารถนำไปเป็นส่วนประกอบหรือต่อยอดในระบบ Optical Character Recognition (OCR) สำหรับอ่านเอกสารภาษาไทย เพื่อลดภาระการคัดลอกข้อมูลด้วยมนุษย์

## 2. แหล่งที่มา จำนวนข้อมูล และการแบ่งชุดข้อมูล
* **แหล่งที่มา:** ชุดข้อมูล [PimAksornThai: Thai Typographic Characters Dataset (Kaggle)](https://www.kaggle.com/datasets/leoideo/printaksorn-a-font-diverse-of-thai-characters)
* **จำนวนข้อมูล:** ภาพทั้งหมด 38,570 ภาพ แบ่งเป็น 95 ประเภท (Classes) 
* **การแบ่งชุดข้อมูล:** แบ่งชุดฝึก (Train) 80% และชุดทดสอบ (Test) 20%
