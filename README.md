# Thai Character Classifier

## 1. แนวคิด ปัญหาที่ต้องการแก้ และประโยชน์
* **แนวคิดและปัญหา:** การแปลงเอกสารภาษาไทยที่มีฟอนต์หลากหลายให้เป็นข้อความดิจิทัลยังคงเป็นความท้าทายในระบบ OCR (Optical Character Recognition) โครงงานนี้จึงพัฒนาแบบจำลอง Machine Learning เพื่อจำแนกภาพตัวอักษรไทย สระ วรรณยุกต์ ตัวเลข และสัญลักษณ์ต่างๆ อย่างแม่นยำ
* **ประโยชน์:** สามารถนำไปเป็นส่วนประกอบหรือต่อยอดในระบบ OCR สำหรับอ่านเอกสารภาษาไทย เพื่อลดภาระการคัดลอกข้อมูลด้วยมนุษย์

## 2. แหล่งที่มา จำนวนข้อมูล และการแบ่งชุดข้อมูล
* **แหล่งที่มา:** ชุดข้อมูล [PimAksornThai: Thai Typographic Characters Dataset (Kaggle)](https://www.kaggle.com/datasets/leoideo/printaksorn-a-font-diverse-of-thai-characters)
* **จำนวนข้อมูล:** ภาพตัวอักษรทั้งหมด 38,570 ภาพ แบ่งเป็น 95 ประเภท (Classes) 
* **การแบ่งชุดข้อมูล:** แบ่งชุดฝึก (Train Set) 80% และชุดทดสอบ (Test Set) 20% โดยมีการปรับขนาดภาพเป็น 64x64 พิกเซล และแปลงเป็นภาพขาวดำ (Grayscale) ก่อนนำเข้าโมเดล

## 3. แบบจำลองที่ใช้ ผลประเมินหลัก และข้อจำกัด
* **แบบจำลองที่ใช้:** โครงข่ายประสาทเทียมแบบคอนโวลูชัน (Convolutional Neural Network - CNN) พัฒนาด้วย TensorFlow/Keras
* **ผลการประเมินหลัก:** มีความแม่นยำ (Accuracy) บนชุดทดสอบที่ 93.61% เมตริกหลักที่ใช้คือ Classification Report (Precision, Recall, F1-score)
* **ข้อจำกัด:** โมเดลอาจยังมีความสับสนระหว่างคลาสที่มีลักษณะโครงสร้างคล้ายคลึงกันมากเมื่ออยู่ต่างฟอนต์ เช่น ฎ กับ ฏ หรือ ข กับ ช

## 7. คำอธิบายไฟล์และโฟลเดอร์สำคัญ
* datasets/: พื้นที่จัดเก็บชุดข้อมูลรูปภาพทั้งหมด รวมถึงไฟล์ master_file.csv ที่ใช้จับคู่ตัวอักษร
